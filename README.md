# آینه

ربات تلگرامی «آینه» به کاربر کمک می‌کند برداشت خودش از ویژگی‌های شخصیتی‌اش را با نگاه جمعی آدم‌هایی که او را می‌شناسند مقایسه کند.

> آینه تست یا ابزار تشخیص روان‌شناختی نیست؛ یک تجربه اجتماعی برای خودشناسی و گفت‌وگوست.

## امکانات MVP

- ربات عادی تلگرام با Long Polling؛ بدون Mini App
- ساخت آینه با ۸ سؤال کوتاه
- لینک دعوت ناشناس با Telegram Deep Link
- جلوگیری از پاسخ تکراری
- پیش‌نمایش رایگان بعد از ۳ پاسخ
- پرداخت آنلاین زیبال با تأیید خودکار callback
- بازشدن خودکار گزارش بعد از پرداخت موفق
- گزارش کامل با OpenAI و گزارش جایگزین بدون API
- کارت تصویری قابل‌اشتراک
- پنل آماری ساده با دستور `/admin`
- لندینگ و صفحه حریم خصوصی روی دامنه

## Secrets لازم در GitHub Actions

در `Settings → Secrets and variables → Actions`:

- `HOST`: آی‌پی سرور
- `PASS`: رمز کاربر root سرور
- `BOTTOKEN`: توکن BotFather
- `OPENAIAPIKEY`: کلید OpenAI؛ اختیاری ولی توصیه‌شده
- `ADMIN_TELEGRAM_IDS`: شناسه عددی ادمین؛ برای چند ادمین با کاما جدا شود
- `ZIBALMERCHANT`: کد merchant زیبال

کد merchant، توکن و کلید API عمداً داخل ریپوی Public قرار نمی‌گیرند.

## جریان پرداخت

1. کاربر داخل ربات روی «پرداخت و باز کردن گزارش کامل» می‌زند.
2. لینک امضاشده روی `https://ayeneh.hamooncloud.ir` یک تراکنش زیبال می‌سازد.
3. کاربر به صفحه رسمی زیبال منتقل می‌شود.
4. زیبال کاربر را به `/payment/callback` برمی‌گرداند.
5. سرور تراکنش را مستقیم از API زیبال verify می‌کند، مبلغ را با سفارش تطبیق می‌دهد و گزارش را باز می‌کند.
6. ربات به‌صورت خودکار پیام موفقیت و دکمه گزارش را برای کاربر می‌فرستد.

شماره کارت و ارسال رسید در مسیر جدید استفاده نمی‌شود. جدول پرداخت‌های دستی فقط برای حفظ رکوردهای قدیمی دیتابیس باقی مانده است.

## اجرا و دیپلوی

Push روی `main`، Workflow دیپلوی را اجرا می‌کند. روی سرور Docker نصب، پروژه در `/opt/ayeneh-app` Clone و سرویس‌ها با Docker Compose اجرا می‌شوند.

رکورد A دامنه `ayeneh.hamooncloud.ir` باید به IP موجود در `HOST` اشاره کند. پورت‌های 80 و 443 نیز باید باز باشند. Caddy گواهی HTTPS را خودکار دریافت می‌کند.

اجرای محلی:

```bash
cp .env.example .env
docker compose up --build
```

سلامت سرویس:

```bash
curl http://localhost:8000/health
```
